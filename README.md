# DevSphere

Smart Recruitment Matching Platform.

## Project Overview

DevSphere is a recruitment platform designed to connect Job Seekers and Employers through structured profiles, secure workflows, and deterministic matching.

## Technology Stack

### Backend
- ASP.NET Core Web API
- .NET 8
- C#
- Entity Framework Core
- SQL Server Express

### Frontend
- Angular 19
- TypeScript
- Tailwind CSS

### Authentication
- ASP.NET Core Identity
- JWT

## Development Workflow

- main: final stable branch
- develop: integration branch
- feature branches: member development branches
