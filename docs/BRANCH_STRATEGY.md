# Branch Strategy

## Main Branch

main

Purpose:
Final stable release.

Rules:
- Protected branch
- PR required
- No direct push


## Develop Branch

develop

Purpose:
Integration branch.

Rules:
- Protected branch
- PR required
- Testing before release


## Feature Branches

Format:

feature/member-task-name


Examples:

feature/abigayil-auth

feature/jeni-jobseeker

feature/thikalnila-employer

feature/musaddiq-matching
