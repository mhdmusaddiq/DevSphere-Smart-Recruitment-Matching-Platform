# DevSphere - Smart Recruitment Matching Platform

## Overview

DevSphere is a smart recruitment matching platform designed to connect job seekers and employers through structured profiles, secure workflows, and intelligent matching processes.

The platform focuses on:
- Job seeker profile management
- Employer vacancy management
- Secure authentication
- Candidate-job matching
- Application workflow management

## Technology Stack

### Backend
- ASP.NET Core Web API
- .NET 8
- C#
- Entity Framework Core
- SQL Server

### Frontend
- Angular 19
- TypeScript
- Tailwind CSS

### Authentication
- ASP.NET Core Identity
- JWT Authentication

### Development Tools
- Visual Studio
- Visual Studio Code
- GitHub
