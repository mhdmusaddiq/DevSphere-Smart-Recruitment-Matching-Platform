# Development Workflow

## Workflow

Issue
↓
Feature Branch
↓
Development
↓
Testing
↓
Commit
↓
Push
↓
Pull Request
↓
Code Review
↓
Develop Merge
↓
Integration Testing
↓
Main Release


## Rules

- No direct push to main
- No direct push to develop
- All feature work must use feature branches
- Every change requires review before merge
- Members work only inside assigned ownership areas


## Pull Request Requirements

Every PR should include:

- Description of changes
- Testing evidence
- Related issue
- Screenshots if UI changes exist
